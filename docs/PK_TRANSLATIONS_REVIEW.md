string as it appears in the app. `{0}` and `{1}` are filled in by the app (a name, a number of minutes, a score): keep them as they are,
in the right place for the language. To correct one, edit its line in `tool/i18n/tr_<code>.tsv` (the number in the first column is the
key number shown here), then run `python3 tool/i18n/gen.py`.
